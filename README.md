# Корпоративный портал corporate.admsr.ru

Веб-приложение корпоративного портала на Vue 3, Vite, Nuxt UI и Tailwind CSS.

## Требования

- **Node.js** 18+ и **npm** (для фронтенда)
- **PHP** 8+ (опционально, для API мероприятий)

## Установка зависимостей

### 1. Клонирование репозитория

```bash
git clone https://github.com/ВАШ_ЛОГИН/corporate.admsr.ru.git
cd corporate.admsr.ru
```

### 2. Установка зависимостей Node.js

```bash
npm install
```

Одной командой устанавливаются все зависимости из `package.json`, в том числе **Tailwind CSS** и **Nuxt UI** — отдельно их ставить не нужно.

### 3. Запуск проекта

**Режим разработки:**

```bash
npm run dev
```

Приложение откроется по адресу (обычно `http://localhost:5173`). Данные мероприятий подгружаются из `src/data/events.json`.

**Сборка для продакшена:**

```bash
npm run build
```

Результат сборки — папка `dist/`.

**Просмотр собранной сборки:**

```bash
npm run preview
```

## Опционально: PHP API для мероприятий

Если нужен бэкенд для CRUD мероприятий (создание/редактирование/удаление через API):

1. Убедитесь, что установлен **PHP** 8+.
2. Запустите встроенный сервер из корня проекта:

   ```bash
   php -S localhost:8080
   ```

3. Настройте фронтенд на запросы к `http://localhost:8080/api/events.php` (сейчас в проекте используется локальный JSON для разработки).

Файл API: `api/events.php`. Данные хранятся в `src/data/events.json`.

## Структура проекта

- `src/` — исходный код Vue-приложения
- `src/pages/` — страницы (в т.ч. `Events/` — мероприятия)
- `src/data/events.json` — данные мероприятий (локальный режим)
- `api/events.php` — PHP API для мероприятий
- `public/` — статические файлы (favicon и т.д.)
