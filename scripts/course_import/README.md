# Импорт курса из архива материалов

Размещает курс «Раздел 1. Основы и безопасная работа с ИИ» из архива
(`NN Тема/` с PDF, MP4, DOCX, `Сопроводительный текст.txt`, `Тест.docx`)
через API портала — так же, как это сделал бы админ в интерфейсе.
Создаётся **черновик**; публикация и назначение — в интерфейсе.

Нужно: Python 3 с `python-docx` и `requests`.

```bash
python scripts/course_import/parse_tests.py "<папка архива>" tests.json
python scripts/course_import/import_course.py "<папка архива>" tests.json <адрес портала> <логин> <пароль>
```

- `parse_tests.py` — разбирает `Тест.docx`: правильный ответ выделен красным;
  таблицы «соотнесите» и «распределите» по ключу вида «А4 Б3 …» / «А12 Б35»
  разворачиваются в вопросы с одним ответом (типа «соотнесение» в модуле тестов
  нет). Печатает число вопросов и вопросы, где правильных ответов не ровно один.
- `import_course.py` — создаёт курс (категория «Безопасность», без итогового
  теста и сертификата), темы с сопроводительным текстом, загружает файлы
  (до 50 МБ) и тесты тем без проходного балла. Состав тем и названия тестов —
  в начале скрипта.

Проверено 2026-09-28 на локальной БД: 5 тем, 10 материалов, 103 вопроса;
курс пройден сотрудником целиком, все тесты — 100 %.
