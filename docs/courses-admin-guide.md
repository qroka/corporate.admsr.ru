# Руководство администратора: учебные курсы

Пошаговый UX в портале. Префикс маршрутов: `/admin/courses`. Нужна роль **admin** (`user_group = admin`) и активный `sessionToken` после входа.

---

## 1. Создать курс

1. Откройте **Управление курсами** → `/admin/courses`.
2. **Новый курс** → `/admin/courses/create`.
3. Укажите название (обязательно), при необходимости категорию, краткое описание, обложку, флаги:
   - последовательное прохождение тем;
   - дедлайн по умолчанию (дни);
   - обязательный итоговый тест / проходной балл версии.
4. Сохранение создаёт курс + **версию 1 (draft)** и открывает workspace: `/admin/courses/:courseId`.

Дальнейшее редактирование контента возможно, пока версия в статусе **черновик**.

---

## 2. Темы

1. В workspace добавьте тему (`/admin/courses/:courseId/topics/create`) или отредактируйте существующую.
2. Задайте заголовок, описание, обязательность, минимальное активное время (секунды), правило завершения.
3. Порядок тем — drag-and-drop / API `course_topics_order` (влияет на sequential unlock у сотрудников).

Рекомендация: сначала структура тем, затем материалы и тесты.

---

## 3. Материалы

1. В теме: **Новый материал** → `/admin/courses/.../materials/create`.
2. Типы:
   - **rich_text** — текст/HTML в редакторе;
   - **file / pdf / image / video** — загрузка файла;
   - **link** — внешняя ссылка.
3. Отметьте обязательность и `minimumActiveSeconds`, если нужно удержание на материале.
4. Загрузка идёт через `course_materials_upload` на серверный каталог uploads; сотрудники читают через `course_file.php`, не по прямой публичной ссылке.

---

## 4. Тесты

### Промежуточный тест темы

1. `/admin/courses/:courseId/topics/:topicId/test`
2. Создайте тест (вопросы, варианты, правильные ответы, проходной балл).
3. Один тест на тему. Форма хранится в `test_forms`, в списке `/tests` **не видна**.

### Итоговый тест

1. `/admin/courses/:courseId/final-test`
2. При создании обычно включается `requireFinalTest` на версии.
3. Один final на версию.

Публичная ссылка `/t/:token` для этих тестов **не используется**.

---

## 5. Настройки и превью

- **Настройки** `/admin/courses/:courseId/settings` — метаданные курса/версии.
- **Превью** `/preview` — как выглядит структура.
- **Проверка** `/review` — готовность к публикации (ошибки readiness).

Либо вызовите readiness на API: `courses_readiness.php`.

Типичные блокеры публикации:

- нет тем / обязательная тема без материалов;
- у обязательного теста нет вопросов или нет правильных ответов;
- требуется final, но он не создан / нет проходного балла.

---

## 6. Публикация

1. `/admin/courses/:courseId/publish`
2. При успехе версия → `published`, связанные тесты тоже публикуются.
3. После публикации контент версии **редактируется на месте**: правки сразу видят сотрудники, проходящие курс, новая версия не создаётся (хаб показывает об этом предупреждение). Повторно опубликовать нельзя — страница публикации для опубликованного курса предлагает перейти к назначению.

Архивация: снять с назначения новых сотрудников, статус `archived`.

---

## 7. Назначение

1. `/admin/courses/:courseId/assign`
2. Выберите сотрудников поимённо и/или в поле «Подразделения (ОФО)» — подразделение (опционально «включая вложенные») **или «Все сотрудники»**. «Все сотрудники» и конкретные ОФО взаимоисключающие.
3. «Когда»: **дата начала** (до неё курс нельзя начать — сотрудник видит «Откроется …») и **«Пройти до»** — последний день срока; со следующего дня курс просрочен. Если срок не указан, применяется «Срок прохождения по умолчанию» из настроек курса — N дней **с момента, когда сотрудник получил курс**; иначе срока нет.
4. «Назначить…» открывает подтверждение со списком получателей и их числом → «Назначить».

Создаются `course_assignments` и `course_enrollments`. Уже имеющие активную запись на эту версию пропускаются (`skipped`); попавший в несколько целей получает одну запись.

**Назначения на ОФО и «Все сотрудники» постоянные** (ADR-036). Курс получат и те, кого на момент назначения не было в списке:

- кто ещё ни разу не входил — при первом входе («Все сотрудники»; учётная запись у них уже может быть — её создаёт синхронизация с ASU, но подразделение пустое);
- кто выберет подразделение на экране приветствия или сменит его в профиле — сразу после сохранения (назначение на ОФО);
- в любом случае — при открытии «Моего обучения».

Кому назначение отменили на экране результатов, тому по этому же назначению курс повторно не выдаётся. Остановить выдачу новым сотрудникам можно, сняв курс с публикации. В подтверждении «Все сотрудники» видно, сколько получателей ещё не выбрали подразделение; в результатах у них пометка «Подразделение не выбрано».

Отменить назначение участнику — «Результаты» → меню строки (⋮) → **Отменить назначение** (кроме завершивших). Курс пропадает из «Моего обучения», прогресс остаётся в результатах со статусом «Отменён», назначить заново можно в любой момент (ADR-035). Поля «комментарий» в форме нет. Сбросить прогресс — там же, «Обнулить результат».

Срок по умолчанию — «Настройки курса» → **Срок прохождения по умолчанию** (дней): подставляется при назначении, если не выбрана дата «Пройти до».

## 8. Результаты

`/admin/courses/:courseId/results` (`CourseResultsPage.vue`):

1. **Сводка** «Не начали / В процессе / Просрочили / Завершили — N из M». M — назначенные без отменённых. Клик по карточке показывает только этот статус, повторный — снимает фильтр; сводка от фильтра статуса не зависит (считается по поиску и ОФО). «Средний итоговый балл» — только у курса с итоговым тестом.
2. **Фильтры и сортировка:** поиск по ФИО/логину, ОФО, статус; порядок — новые назначения, ФИО, меньше прогресса, ближе срок, давно не заходили. Отменённые всегда в конце и приглушены.
3. **Строка участника:** ФИО и ОФО (или «Подразделение не выбрано — скорее всего, ещё не входил»), статус, полоса прогресса «X/Y тем», срок с подсветкой («Просрочено на N дней» — красным, ≤3 дней — жёлтым), когда последний раз был в курсе; итоговый балл — только при итоговом тесте.
4. **Карточка участника** (справа, на телефоне — под списком с автопрокруткой): должность, почта и телефон ссылками, прогресс, даты (назначен, начал, последняя активность, срок, завершён), время в курсе, тесты (результат в %, попытки, ответы по клику), темы с «материалы X из Y» и временем. Действия — «Обнулить результат», «Отменить назначение».
5. **Excel:** ФИО, логин, должность, ОФО, статус, прогресс, темы, итоговый балл, даты назначения, начала, последней активности, срок, завершение — по текущим фильтрам, до 5000 строк.

## Чеклист перед публикацией

- [ ] Есть хотя бы одна тема с контентом
- [ ] Обязательные материалы заполнены
- [ ] Тесты с правильными ответами
- [ ] Final настроен, если требуется
- [ ] Readiness без ошибок
- [ ] Превью просмотрено
- [ ] Понятен список назначения (ОФО / люди)
